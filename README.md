# Hover Race Challenge

A 2D racing and challenge game prototype developed in C++ for university coursework.

## Features
* Custom 2D game loop and real-time rendering
* Smooth keyboard and mouse input handling for vehicle control
* Collision detection and dynamic score/lap tracking
* Track and level management using configuration files

## Project Structure
* `.cpp` — Core source code and game logic
* `scene.txt` — Scene and environment setup configurations
* `waypoints.txt` — Track waypoint layouts and navigation routes
